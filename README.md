# أباريق | Abareq Cafe

منصة تعريفية ثابتة لمحل أباريق في المدينة المنورة، بهوية شاي دافئة وتجربة عربية/إنجليزية متجاوبة.

## المحتوى

تتضمن الصفحة الرئيسية قصة المكان، اختيارات مقترحة، قائمة قابلة للبحث والتصفية، تقييم Google مع رابط المصدر، موقع الفرع الموثق، خريطة مباشرة، اتصال، واتجاهات، وتبديلًا كاملًا بين العربية والإنجليزية.

## تعديل الأسعار

الأسعار موجودة في ملف `data/prices.json` فقط. كل سجل يحتوي على `name` و`price`، ويُفترض أن تقرأ الواجهة هذا الملف دون تكرار الأرقام داخل HTML أو JavaScript. يجب اعتماد الأسعار مع المحل قبل نشر أي تحديث.

## المصادر والخصوصية

المعلومات العامة، التقييم، العنوان، الهاتف، والصور المرجعية مأخوذة من مصادر عامة، وتحتاج إلى مراجعة دورية. لا يحتوي المشروع على تعليقات أو شهادات مختلقة، ولا يدّعي وجود فروع غير موثقة.

## تشغيل محلي اختياري

يمكن فتح `index.html` عبر خادم ملفات ثابت، لأن تحميل `data/prices.json` يحتاج إلى HTTP في بعض المتصفحات. لا توجد قاعدة بيانات أو مفاتيح سرية في هذا المستودع.


## التفاعلات والواجهة

تتضمن الواجهة الآن شريط تقدم للتمرير، ظهوراً تدريجياً للأقسام، تفاعلات hover خفيفة للبطاقات والقائمة والخريطة، زر عودة للأعلى، قائمة هاتف قابلة للفتح والإغلاق بلوحة المفاتيح، رابط تخطي المحتوى، حالات focus مرئية، ودعم `prefers-reduced-motion` لتقليل الحركة عند طلب النظام ذلك.

## المعاينة والنشر

المصدر الرسمي هو فرع `main` في مستودع GitHub العام. ملف `.github/workflows/pages.yml` مجهز للنشر عبر GitHub Actions، لكن تفعيل Pages يتطلب مرة واحدة من إعدادات المستودع اختيار GitHub Actions كمصدر النشر. إلى أن يتم ذلك، يمكن معاينة الملفات عبر أي خادم static يدعم HTTP؛ فتح `index.html` مباشرة قد يمنع تحميل ملف الأسعار بسبب سياسة المتصفح.

## ملاحظات الإطلاق

قبل الإعلان العام يجب اعتماد الأسعار والأحجام والهاتف والساعات والفروع والصور من المحل، ثم اختبار رابط Pages على الهاتف وسطح المكتب. الصور الحالية جزء من اتجاه التصميم، ويستحسن استبدال أي صورة مفاهيمية بصورة حقيقية يوافق عليها المحل قبل الاستخدام التجاري.
